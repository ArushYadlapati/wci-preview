# wci-preview

Test copy of the West Coast Invitational redesign: https://arushyadlapati.github.io/wci-preview/

It builds and deploys `site/` from the `dev` branch of [WestCoastInvitational/WestCoastInvitational.org](https://github.com/WestCoastInvitational/WestCoastInvitational.org). The Action checks for new commits about every 30 minutes. To update it right away, run **Deploy WCI preview** from the Actions tab.

The real site is unaffected. It's deployed separately from the org repo's `main` branch.
